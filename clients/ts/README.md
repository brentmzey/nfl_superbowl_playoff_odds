# @brentmzey/nfl-superbowl-predictions-client

A strictly typed, read-only TypeScript client for the predictions database on PocketHost
(`POCKETHOST_URL`, e.g. `https://nfl-superbowl-predictions.pockethost.io`). It expands the PocketHost starter
snippet:

```ts
const client = new PocketBase(url)
const records = await client.collection('posts').getFullList({ sort: '-created' })
```

into typed, validated, retried queries against the real collections:

```ts
import { createNflRepository, createPocketBaseSource, describe, urlFromEnv } from '@brentmzey/nfl-superbowl-predictions-client';

const repo = createNflRepository(createPocketBaseSource({ url: urlFromEnv().getOrThrow() }));

const runs = await repo.runs(2026);            // m_simulation_runs, newest first ('-created')
const board = await repo.leaderboard(2026);    // s_latest_team_outlooks, rank order
board.fold(
  (e) => console.error(describe(e)),           // typed error union, nothing thrown
  (rows) => rows.forEach((r) => console.log(r.int_champion_rank, r.str_team_name, r.dbl_champion_prob)),
);
```

## What it adds over the raw SDK

| | |
|---|---|
| **Generated types** | `src/generated/schema.ts` is generated by the Kotlin pipeline from `PocketBaseSchema.kt`. It provides one interface per collection or view (`NflTeam`, `NflGame`, `SimulationRun`, `TeamOutlook`, `SuperBowlMatchup`, `LatestTeamOutlook`, `SchemaMigration`), with snake_case fields exactly as stored and literal unions for `Conference`, `SeasonPhase`, and `StatusCode`. A Kotlin golden test fails the build if the file drifts. |
| **JDBI-style query templates** | `defineQuery({ collection, filter: 'int_season_year = {:season} && str_phase = {:phase}', sort: ['-created'] })`. The compiler parses the filter and types every `{:param}` from the column it is compared with: `phase` must be a `SeasonPhase`, `season` a number. Missing, extra, misspelled, or wrongly typed params, and unknown sort columns, are all compile errors. |
| **Injection-safe binding** | Values are bound through PocketBase's own `filter()` escaping, never concatenated. A runtime guard also rejects missing or unknown params from untyped callers. |
| **Runtime validation** | Every record is checked against the generated field specs before it is returned as `CollectionRecords[C]`. A failure names the collection, record, field, and expected/actual types. |
| **Resilience** | Per-attempt timeout (default 15s), plus exponential back-off with jitter on network errors, timeouts, 429, and 5xx (PocketHost cold starts). 4xx errors are returned immediately. |
| **No throwing** | Every call returns `Result<T, NflClientError>` (the same `fp.ts` style as the sibling repos), and `latestRun` returns an `Optional`. |
| **Config from env** | `urlFromEnv()` reads `POCKETHOST_URL` with no hard-coded fallback. Reads need no credentials because the collections are publicly readable. |

## Query catalogue (`NflQueries`)

`teams` · `leaderboard(season)` · `conferenceLeaderboard(season, conference)` · `runs(season, status)` ·
`latestRun(season)` · `teamTrend(team, season)` · `topMatchups(runId)` · `weekGames(season, phase, week)` ·
`teamGames(team, season)` · `migrations`. The same catalogue exists as JDBI SqlObject templates over the local
SQLite / PostgreSQL replicas (`ReplicaQueries.kt`).

## Develop

```bash
bun install
bun run check        # test:coverage (≥95% lines/functions) && typecheck (tsc strict) && build
bun run test:live    # read-only checks against POCKETHOST_URL
bun run example      # POCKETHOST_URL=... prints the current top 10
```

`test/types.test.ts` holds compile-time tests: each `@ts-expect-error` must stay an error, so `tsc` fails if the
template inference ever weakens.
